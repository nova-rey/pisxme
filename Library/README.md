# PiSXMe Library

This private companion Library branch is a metadata, synthesis, and retrieval corpus,
not a mirror of third-party material. It has three layers: provenance source records,
machine-readable indexes, and task-sized briefs. External and project-derived evidence
are explicitly separate. Consult the index before external research.

Do not add PDFs, NDA material, credentials, paywalled material, or copyrighted
documents without an affirmative redistribution right. Record citations and factual
notes when redistribution is unclear. The public origin is not a Library destination.
