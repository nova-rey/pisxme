# Storage Path-B / M.2 / USB3 brief

Path-B is an isolated qualification candidate, not production CAD authority. Treat
M.2 keying/contact mapping and NVMe/SATA ownership as explicit contracts. Preserve
open gates: PCIe clock treatment, reset/CLKREQ ownership, empty-socket handling,
SSD 3.3-V inrush/thermal budget, and nonselected-interface isolation sequencing.
Use CM5IO context and TI USB3 guidance; retained RTL material is community evidence.
