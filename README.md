# PiSXMe

PiSXMe is an open-hardware compute-appliance carrier project for a Raspberry Pi Compute Module 5 and an NVIDIA Tesla V100 SXM2 module.

This public repository is a recovery/preservation snapshot prepared from verified local source files while the original iCloud-backed checkout contained unavailable File Provider placeholders. It preserves the Rev A design evidence and handoff material; it is not a claim that Rev A is fabrication-ready.

Read [HANDOFF_LINUX_WORKSTATION.md](HANDOFF_LINUX_WORKSTATION.md), [TOOLING_STATUS.md](TOOLING_STATUS.md), [references/REFERENCE_INDEX.md](references/REFERENCE_INDEX.md), and [plans/M6_LINUX_RESTART_CHECKLIST.md](plans/M6_LINUX_RESTART_CHECKLIST.md) before changing the design.

The authoritative active-design hashes and unavailable-source manifest are recorded in [RECOVERY_MANIFEST.md](RECOVERY_MANIFEST.md).
