# Phase 24 endpoint-grid cluster analysis — 2026-09-11

## Current evidence

Native KiCad 10.0.5 full ERC v3 reports 416 `endpoint_off_grid` warnings,
232 `isolated_pin_label` warnings, and 147 `unconnected_wire_endpoint`
warnings. The findings are emitted under the root sheet for the endpoint
class.

The canonical hierarchy contains repeated legacy 3 mm geometry:

- root sheet pins at `(35,47)`, `(35,50)`, `(35,53)`, and so on;
- root wires at the same 3 mm pitch;
- child hierarchical labels/wires at `(5,10)`, `(5,13)`, `(5,16)`, and so on.

These coordinates are not on the native 2.54 mm connection grid and directly
match the repeated ERC findings. This is a generator/source-authoring defect,
not evidence that the electrical interfaces are inherently invalid.

The cluster is not homogeneous: native ERC also identifies unrelated
component and non-contract wire endpoints. Therefore a blanket coordinate
rewrite would be unsafe.

## Root-cause boundary

`phase3_scaffold.py` currently defines `GRID = 2.54` and has a native-grid
`native_root_point()` path, while the canonical sources still retain the old
3 mm serialization. The canonical files were generated by an older scaffold
revision or an earlier output of that path.

The required repair unit is the complete hierarchy contract, regenerated from
one identity table:

1. parent sheet pins and sheet positions;
2. parent wires and direct root links;
3. child hierarchical labels and wires;
4. embedded contract-symbol pins;
5. contract-instance pin UUID associations.

Snapping only one of these layers is explicitly rejected by earlier native
probes because it detaches hierarchy associations. The accepted electrical
identity map remains unchanged.

## Discriminator and disposition

A disposable complete regeneration must reduce the 3 mm contract subset while
preserving native hierarchy `pin_not_connected` at zero, preserving all ten
root/child identity sets, and producing an equivalent exported netlist. The
existing partial/coherent probes did not satisfy that gate and remain rejected.

No canonical hierarchy regeneration is promoted by this analysis. The live
source remains authoritative, with the current warning census at 851 warnings
and zero errors; the next implementation action is a complete identity-driven
contract transformation or a narrowly scoped authoring-path repair that meets
the stated native comparison gate.
