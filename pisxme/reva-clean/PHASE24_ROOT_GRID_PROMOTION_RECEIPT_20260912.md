# Phase 24 root graphical-grid repair — promoted

## Hypothesis and scope

The remaining endpoint warnings were generated by root sheet pins, wires,
labels, and sheet graphics authored at off-grid coordinates. A coherent
root-only transform was selected: snap every root graphical `at`/`xy` pair to
the KiCad 1.27 mm grid while leaving all child circuit geometry unchanged.
