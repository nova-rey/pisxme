## Discriminator result

The 5.1 mm Ethernet candidates are not acceptable exact floorplans because
their native component-body envelopes intrude into J7/SERVICE/power geometry.
The outboard Ethernet candidate reduces that intrusion but lengthens storage
and still conflicts with the power corridor. The PCIe exchange is rejected
because it worsens the sensitive PCIe anchor without a balanced global gain.
SERVICE is not an exchange target because it is already source-local.
