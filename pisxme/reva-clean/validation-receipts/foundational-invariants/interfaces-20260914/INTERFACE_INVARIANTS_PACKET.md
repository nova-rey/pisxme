## High-impact interface findings for Root

1. `IF-V100-PCIe-X1`, `IF-PCIE-CLOCK-RESET`, and `IF-SXM2-J1-CONTACT-BOUNDARY` establish the selected x1 interface scope, but do not close physical routing or undocumented endpoint reset/power behavior. The J1 reassessment is sufficient for the bounded source/net contract; unknown contacts remain unknown.
2. Path A is the selected production storage implementation. The source contract is coherent across TUSB9261, JMS583, selectors, and TE M-key mapping, while complete integrated mode isolation and route validation remain `UNPROVEN`.
3. The official CM5IO source gives a quantitative boundary: PCIe Gen 2 x1 is supported; Gen 3 x1 is experimental/unsupported. Rev A acceptance must therefore require Gen 2 x1 behavior and must not claim Gen 3.
4. The current package does not make any product-level power-capacity claim. The separate power/invariant package must bind the 300 W sustained / 330 W peak envelope and determine whether the two-circuit input topology is superseded. This packet intentionally reports that dependency rather than inferring source capacity from connector contact count.
5. Ethernet schematic support is closed, but exact `TRJG0926HENL` manufacturer/procurement evidence and integrated link behavior remain open. Firmware/configuration and fabricated endpoint behavior remain `UNPROVEN`.
