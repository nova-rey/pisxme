# EEWorld JMS578/M.2 reference capture

This directory contains a minimal, already-downloaded capture of the EEWorld
“M.2 SATA to hard drive adapter board based on JMS578” implementation used as
secondary engineering evidence for the PiSXMe storage island. The original
page is:

<https://en.eeworld.com.cn/Reference_Designs/detail/5f3ad50c>

The KiCad schematic/PCB/project and the source README are retained for
inspection. Firmware binaries, generated Gerbers, CAD shells, and the source
repository history were intentionally not copied. Treat this as reference
material, not as a PiSXMe-ready block; symbol/footprint/pin mapping and
licensing must be rechecked before reuse.
