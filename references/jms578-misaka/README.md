# MiSaKa JMS578 reference capture

This directory preserves the schematic, PCB, extracted netlist, and local
analysis report from the MiSaKa JMS578 USB/SATA implementation used during the
PiSXMe disposable-island studies. It corroborates clock, reset, power, USB3,
and SATA topology but is secondary/empirical evidence. It is not a promoted
PiSXMe source block.
