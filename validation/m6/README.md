workstation does not depend on `/private/tmp`. They are evidence, not active
source and not release signoff. The authoritative restart boundary is
`plans/M6_LINUX_RESTART_CHECKLIST.md`.

- `M6_ARCHITECTURE_BLOCKER_REPORT.md` — latest architecture/routability status
- `M6_RECONSTRUCTION_STATUS.md` — source-bound reconstruction disposition
- `M6_ETHERNET_SATA_REPLAN_CHECKPOINT.md` — provisional Ethernet/SATA decision
- `M6_ESD_TRUTH_CHECKPOINT.md` — corrected ESD pad facts
- `M6_USB_REBUILD_CHECKPOINT.md` — failed USB reconstruction evidence
- `U16_BLOCKER_STATUS.md` and `U16_PACKAGE_CHECKPOINT.md` — regulator status
- `SCHEMATIC_ISLAND_ATTEMPT_REPORT.md` — failed source-bound island attempt
- `SCHEMATIC_AUTHORING_TOOLING_REPORT.md` — direct-backend authority gap
